# 📖 IELTS Academic Reading — คู่มือกลยุทธ์ (วิธีทำให้ได้คะแนน)

**สร้าง:** 10 ส.ค. 2569 · สำหรับ Ness (และใช้ร่วมกับออมได้)
**นี่คือคู่มือ "วิธีทำ" ถาวร** — ไม่ใช่โจทย์รายวัน เปิดอ่านซ้ำได้ทุกครั้งที่ทำ Reading

---

## 1. กติกาการให้คะแนน — รู้ก่อนแล้วจะเปลี่ยนวิธีทำทันที

- **40 ข้อ = 40 คะแนนดิบ** ตอบถูก 1 ข้อ = 1 คะแนน ไม่มีคะแนนติดลบ ไม่มีหักคะแนนตอบผิด
- **→ ห้ามเว้นว่างแม้แต่ข้อเดียว** ไม่รู้ก็เดา เดาผิดไม่เสียอะไร เว้นว่างเสียคะแนนฟรี
- คะแนนดิบแปลงเป็น band ตามตาราง (ดู `ielts-shared-mock-plan.md`) — **ราว 30/40 = band 7.0**
- **เวลารวม 60 นาที รวมเวลาเขียนคำตอบ** ไม่มีเวลาโอนคำตอบเพิ่มแบบ Listening — บริหารเวลาด้วยตัวเอง

---

## 2. ลำดับการทำที่แนะนำ (ต่อ 1 passage)

```
1. สแกนหัวข้อ + ประโยคแรกของแต่ละย่อหน้า (1-2 นาที) — ยังไม่อ่านละเอียด
   เป้า: รู้ว่า passage นี้พูดเรื่องอะไร แบ่งเป็นกี่ส่วน แต่ละส่วนพูดเรื่องอะไรคร่าวๆ
2. อ่านคำถามทั้งหมดก่อน (1-2 นาที) — ขีดเส้นใต้ keyword ที่จะใช้ค้นหาในบทความ
3. ไล่หาคำตอบตามลำดับ (ส่วนใหญ่คำถามเรียงตามลำดับย่อหน้าในบทความ
   ยกเว้น Matching Headings และ Matching Information ที่อาจไม่เรียง)
4. ข้อไหนติดเกิน 60-90 วิ → ข้ามไปก่อน กลับมาทีหลัง อย่าจมกับข้อเดียว
5. เหลือเวลา 2 นาทีสุดท้าย → เดาให้ครบทุกข้อที่ว่าง
```

**เวลาโดยประมาณ:** passage 1 = 17 นาที · passage 2 = 20 นาที · passage 3 = 23 นาที (ยากขึ้นเรื่อยๆ)

## 3. เทคนิคเฉพาะแต่ละประเภทคำถาม

### 🔴 True / False / Not Given — จุดที่เสียคะแนนมากที่สุด

| คำตอบ | ความหมาย | สัญญาณที่ต้องหา |
|---|---|---|
| **TRUE** | บทความยืนยันตรงกับที่โจทย์บอก | มีประโยคในบทความที่ความหมายตรงกัน (คำอาจไม่เหมือนกันเป๊ะ แต่ความหมายตรง) |
| **FALSE** | บทความบอก**ตรงข้าม** | มีประโยคในบทความที่ขัดแย้งชัดเจน — ต้องชี้นิ้วไปที่ประโยคนั้นได้ |
| **NOT GIVEN** | บทความ**ไม่ได้พูดถึง**เรื่องนี้เลย | หาเท่าไหร่ก็ไม่เจอประโยคที่เกี่ยวข้องโดยตรง |

**วิธีเช็คให้แม่น — ถามตัวเอง 2 คำถามนี้เสมอ:**
1. *"ผมชี้ประโยคในบทความที่พูดเรื่องนี้ได้ไหม?"* — ชี้ไม่ได้เลย = **NOT GIVEN**
2. ถ้าชี้ได้ → *"ประโยคนั้นบอกเหมือนโจทย์ หรือขัดแย้งกับโจทย์?"* — เหมือน = **TRUE** / ขัดแย้ง = **FALSE**

**กับดักที่ทำให้พลาดบ่อยที่สุด:**
- ⚠️ **ใช้ความรู้นอกบทความ** — ต่อให้รู้เรื่องนั้นจริงจากที่อื่น ถ้าบทความไม่พูดถึง = NOT GIVEN เสมอ ห้ามตอบจากสามัญสำนึก
- ⚠️ **คำเชิงเน้นย้ำ** เช่น *always, never, only, all, completely* — โจทย์ที่ใช้คำเหล่านี้มักเป็น FALSE เพราะบทความมักเขียนแบบมีเงื่อนไข ไม่ใช่แบบเบ็ดเสร็จ
- ⚠️ **บทความพูดถึงหัวข้อนั้น แต่ไม่ได้พูดถึงรายละเอียดที่โจทย์ถาม** — เช่น บทความพูดเรื่อง "ราคาทอง" แต่โจทย์ถามเรื่อง "ราคาทองปีหน้า" ถ้าบทความไม่ได้พยากรณ์อนาคต = NOT GIVEN แม้หัวข้อจะเกี่ยวข้องกัน

### 🟡 Yes / No / Not Given — คนละแบบกับ True/False/NG

ใช้กับ passage ที่มี**ความเห็นหรือข้อโต้แย้งของผู้เขียน** (ไม่ใช่ข้อเท็จจริงทั่วไป)
- **YES** = ตรงกับ**ความเห็น**ของผู้เขียน · **NO** = ขัดกับความเห็นผู้เขียน · **NOT GIVEN** = ผู้เขียนไม่ได้แสดงความเห็นเรื่องนี้
- วิธีแยก: มองหาคำที่ผู้เขียนใช้แสดงจุดยืน เช่น *argues that, claims, in my view, it is likely that*

### 🟢 Matching Headings — อ่านโครง ไม่ใช่อ่านรายละเอียด

- **อ่านแค่ประโยคแรกกับประโยคสุดท้ายของแต่ละย่อหน้าก่อน** — ส่วนใหญ่พอบอกใจความหลักได้แล้ว ไม่ต้องอ่านทั้งย่อหน้า
- หัวข้อที่ถูกต้องต้องครอบคลุม**ใจความหลักทั้งย่อหน้า** ไม่ใช่แค่รายละเอียดเล็กๆ ที่อยู่ตรงกลาง
- **มีหัวข้อลวงเกินมาเสมอ** (เช่น 7 หัวข้อ 4 ย่อหน้า) — หัวข้อที่ไม่ถูกใช้มักจะจับใจความแค่บางส่วนของย่อหน้า หรือใจความที่ไม่มีในบทความเลย

### 🔵 Matching Information / Features — ใช้คำเฉพาะเป็นหลักหมุด

- โจทย์แบบนี้ถามว่า "ข้อมูลนี้อยู่ย่อหน้าไหน" หรือ "อธิบายลักษณะของใคร"
- **มองหาชื่อเฉพาะ ตัวเลข ปี ชื่อคน ชื่อสถานที่** เป็นหลักหมุดค้นหา เร็วกว่าอ่านทั้งย่อหน้า
- คำถามกลุ่มนี้**ไม่เรียงตามลำดับย่อหน้า** ต่างจากคำถามส่วนใหญ่ — ต้องกวาดสายตาทั้ง passage

### 🟣 Summary / Sentence / Note Completion — กฎคำจำกัดที่ต้องเป๊ะ

- **นับคำตามกติกาเป๊ะ** เช่น "NO MORE THAN THREE WORDS" — 4 คำ = ผิดทันที ต่อให้ความหมายถูก
- ตัวเลขนับเป็น 1 คำเสมอ (เช่น "1990" = 1 คำ)
- **ห้ามเปลี่ยนรูปคำ** ถ้าต้นฉบับเป็น noun ให้ตอบเป็น noun อย่าเปลี่ยนเป็น verb เอง — ต้องลอกคำจากบทความมาตรงตัว (บางข้อสอบอนุญาตให้เปลี่ยนรูป บางข้อไม่ — อ่านคำสั่งให้ชัด)
- **สะกดผิด = ผิด** เหมือน Listening
- เช็คไวยากรณ์ของประโยคที่เว้นว่าง — บอกใบ้ว่าต้องเติมคำชนิดไหน (noun/verb/adjective)

### ⚪ Multiple Choice — อ่านให้ครบทุกตัวเลือกก่อนเลือก

- อย่าเลือกตัวเลือกแรกที่ "ดูเหมือนถูก" — ต้องอ่านครบ 4 ตัวเลือกก่อนตัดสินใจเสมอ
- ตัวลวงมักเป็นข้อความที่**ถูกในโลกจริงแต่บทความไม่ได้พูดถึง** หรือ**ถูกครึ่งเดียว** (ถูกกับส่วนแรกของประโยค ผิดกับส่วนหลัง)
- หาคำในบทความที่ paraphrase ตรงกับตัวเลือก ไม่ใช่หาคำที่สะกดเหมือนกันเป๊ะ (ข้อสอบจงใจเปลี่ยนคำ)

## 4. 5 ข้อผิดพลาดที่ทำให้เสียคะแนนบ่อยที่สุด (เรียงจากที่พบบ่อยสุด)

1. **สับสน NOT GIVEN กับ FALSE** — จำไว้: NG = "ไม่พูดถึง", FALSE = "พูดถึงแต่ตรงข้าม" ถ้าชี้ประโยคไม่ได้ = NG เสมอ
2. **ใช้ความรู้/สามัญสำนึกนอกบทความ** — ตอบจากสิ่งที่บทความเขียนเท่านั้น
3. **เกินจำนวนคำที่กำหนดใน Completion** — นับทุกครั้งก่อนเขียนคำตอบสุดท้าย
4. **เสียเวลากับข้อเดียวนานเกินไป** — ตั้งกฎ 90 วินาที ถ้าเกินให้ข้าม กลับมาทีหลัง
5. **ไม่อ่านคำสั่งของแต่ละกลุ่มคำถามให้ครบ** — แต่ละกลุ่มมีกติกาต่างกัน (จำนวนคำ, เปลี่ยนรูปคำได้ไหม, มีตัวเลือกเกินไหม)

## 5. เช็คลิสต์ก่อนส่งคำตอบ (30 วินาทีสุดท้าย)

```
□ ตอบครบทุกข้อ ไม่มีข้อว่าง
□ ข้อ Completion ไม่มีข้อไหนเกินจำนวนคำที่กำหนด
□ สะกดคำถูกต้อง (โดยเฉพาะคำที่ลอกมาจากบทความ)
□ เลข/ตัวอักษรที่ต้องเลือก (เช่น A-G) เขียนตรงกับที่โจทย์ขอ
```
