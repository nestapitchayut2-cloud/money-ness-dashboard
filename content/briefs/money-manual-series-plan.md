# 📘 ซีรีส์: คู่มือการเงินมนุษย์เงินเดือน

**เพจ:** The Money Ness
**รูปแบบ:** บทความ long-form ลงเพจ (โพสต์ทีละบท นึกออกอันไหนโพสอันนั้น) → รวมเล่มเป็นหนังสือทีหลัง
**กลุ่มเป้าหมาย:** คนทำงานประจำ อายุงาน 0–5 ปี เงินเดือน ~18,000–45,000 รายได้ทางเดียวคือเงินเดือน
**ระดับ:** เริ่มต้น → กลาง
สร้างแผน: 4 ก.ย. 2026

## 🎯 จุดยืนของซีรีส์ (พูดให้คนอ่านฟังในโพสต์แรก)

ไม่ใช่คู่มือรวยเร็ว ไม่ใช่คอร์สลงทุน — เป็น**ลำดับการจัดการเงิน**สำหรับคนที่มีเงินเข้าเดือนละครั้ง
เริ่มจากศูนย์ ทีละเรื่อง เรื่องละโพสต์ อ่านจบแล้วทำได้เลยภายในสัปดาห์นั้น

**ความเชื่อที่ซีรีส์นี้อยากเถียง:** "เงินเดือนน้อย ยังไม่ต้องวางแผนการเงินหรอก" —
จริงๆ ยิ่งเงินน้อยยิ่งต้องจัด เพราะพลาดทีนึงเจ็บกว่าคนเงินเยอะ

**เสียงของ Ness (ตาม Style Guide):** monologue เพื่อนเล่าให้เพื่อนฟัง / ไม่ใช่ครู ไม่ใช่ผู้เชี่ยวชาญ /
ยอมรับว่าตัวเองก็เคยพลาด / ทุกจุดมีตัวเลขจริงของไทย / จบด้วย CTA คอมเมนต์หรือเซฟ ไม่ hard sell

## 🧱 โครงบทความมาตรฐาน (ทุกบทใช้โครงนี้ = 1 โพสต์ = 1 บทในหนังสือ)

1. **Hook** (1–2 ประโยค) — ความเชื่อที่อยากเถียง หรือ ตัวเลขที่ทำให้อึ้ง
2. **ทำไมเรื่องนี้สำคัญกับคนเงินเดือน** — context ส่วนตัว/สถานการณ์จริง
3. **เนื้อหาหลัก 3–4 จุด** — แต่ละจุดมี: ประเด็น + ตัวเลขจริงไทย + มุมมอง Ness
4. **กับดักที่คนเงินเดือนเจอบ่อย** (1–2 อัน)
5. **ลองทำเลยอาทิตย์นี้** — action ที่ทำเสร็จได้ใน 7 วัน
6. **สรุป 3 บรรทัด**
7. **CTA** — เลือก 1: คอมเมนต์เถียง / เซฟไว้ใช้ / คำถามชวนคิด (+ Quiz ถ้ามี)
8. **Gemini image brief** — แยกท้ายไฟล์ ตาม template ใน Style Guide (prompt ก้อนเดียว + hex code)

**Metadata ท้ายแต่ละไฟล์** (ไว้ตอนรวมเล่ม): บทที่ / ระดับ / เชื่อมกับบท / เครื่องมือประกอบ / วันที่โพส / ยอด engagement

## 📝 บรีฟรายบท (5 หัวข้อแรกที่ Ness คิดออก)

### บท 2 — บัตรเครดิตใบแรก
- **Hook:** "บัตรเครดิตไม่ใช่เงินเพิ่ม 50,000 — มันคือบิลที่ยังมาไม่ถึง"
- **ความเชื่อที่เถียง:** "มีบัตรเครดิต = เป็นหนี้ / คนมีวินัยไม่ใช้บัตร" → จริงๆ บัตรคือเครื่องมือสร้างประวัติ + ได้เครดิตคืน ถ้าจ่ายเต็มทุกงวด
- **ตัวเลขจริงไทย:**
  - เพดานดอกเบี้ย + ค่าธรรมเนียมบัตรเครดิต = 16% ต่อปี (ประกาศ ธปท.)
  - จ่ายขั้นต่ำ 8% ของยอด — จ่ายขั้นต่ำอย่างเดียวหนี้ 20,000 ใช้เวลาปลดเกิน 2 ปี ดอกเบี้ยรวมหลายพัน
  - รายได้ขั้นต่ำสมัคร (ทั่วไป) 15,000 บาท/เดือน
  - เครดิตบูโร (NCB) เก็บประวัติย้อนหลัง 3 ปี — ตกงวดครั้งเดียวติดไปทั้งตอนขอสินเชื่อบ้าน
- **3 จุดหลัก:** (1) บัตรทำงานยังไง รอบบิล/วันครบกำหนด/ระยะปลอดดอกเบี้ย (2) กับดักจ่ายขั้นต่ำ + คณิตศาสตร์ดอกเบี้ยทบ (3) ใช้บัตรให้เป็นประโยชน์: cashback/ไมล์, สร้างเครดิตสกอร์, สิทธิผ่อน 0% ที่ควร/ไม่ควรใช้
- **กับดัก:** "ผ่อน 0% ก็คือฟรี" → ไม่ฟรีถ้ามันทำให้ซื้อของที่ไม่ได้ตั้งใจซื้อ / หมุนหลายใบจนไม่รู้ยอดรวม
- **ลองทำเลย:** ตั้งหักบัญชีอัตโนมัติจ่าย **เต็มจำนวน** ทุกงวด + จดวันครบกำหนดลงปฏิทิน
- **CTA:** คำถามชวนคิด — "บัตรใบแรกของคุณ กดเพราะอยากได้ของแถม หรือเพราะจำเป็นจริงๆ?"
- **ภาพ:** Conceptual still life — บัตรเครดิตวางบนตาชั่ง อีกฝั่งเป็นซองบิลพับ / โทน chiaroscuro

### บท 1 — อ่านสลิปเงินเดือนให้ออก
- **Hook:** "เงินเดือน 30,000 แต่เข้าบัญชี 27,000 — 3,000 ที่หายไปไม่ได้หายฟรี มันคือสิทธิของคุณ"
- **ความเชื่อที่เถียง:** "ดูแค่ยอดเงินเข้าก็พอ" → ช่องที่ไม่เคยอ่าน (ประกันสังคม, PF, ภาษีหัก ณ ที่จ่าย, YTD) คือของที่ได้คืนตอนยื่นภาษี/ตอนลาออก
- **ตัวเลขจริงไทย:**
  - ประกันสังคม ม.33 = 5% ของค่าจ้าง สูงสุด 750 บาท/เดือน (ฐานสูงสุด 15,000) → ปีละสูงสุด 9,000 ลดหย่อนภาษีได้
  - กองทุนสำรองเลี้ยงชีพ: พนักงานเลือกสมทบ 2–15% ของเงินเดือน — เพิ่มเองได้ นายจ้างมักสมทบให้ตามสัดส่วน = เงินเดือนขึ้นฟรี
  - ภาษีหัก ณ ที่จ่าย = บริษัทประมาณการภาษีทั้งปีหารเฉลี่ยหักล่วงหน้า ถ้าลดหย่อนเยอะกว่าที่แจ้ง → ได้คืน
- **3 จุดหลัก:** (1) ฝั่งรายได้ อะไรคิดภาษี/ไม่คิด (เงินเดือน/OT/ค่าตำแหน่ง vs ค่าเดินทางเหมาจ่ายบางแบบ) (2) ฝั่งหัก แต่ละช่องคืออะไร เงินไปไหน (3) ช่อง YTD ทำไมต้องเก็บสลิปทุกเดือน
- **กับดัก:** ไม่เคยเช็กว่า PF ตั้งไว้กี่ % (หลายคนติดค่า default ต่ำสุด) / เข้าใจว่าโบนัสจะได้เต็ม (โบนัสโดนหักภาษี ณ ที่จ่ายก้อนใหญ่)
- **ลองทำเลย:** เปิดสลิปเดือนล่าสุด จด 3 ตัวเลข — เงินเข้าจริง, ภาษีหัก ณ ที่จ่ายสะสม (YTD), PF สะสม
- **CTA:** เซฟ — "ไว้เปิดดูตอนสิ้นปีก่อนยื่นภาษี"
- **เชื่อมเครื่องมือ:** เว็บวางแผนรายได้ & ภาษี (บท 6)

### บท 6 — วิธีลดหย่อนภาษี
- **Hook:** "เงินคืนภาษีไม่ใช่โบนัสจากรัฐ มันคือเงินคุณที่จ่ายเกินไปทั้งปี — และปีนี้คุณเอาคืนได้เท่าไรขึ้นอยู่กับ 2 เดือนสุดท้าย"
- **ความเชื่อที่เถียง:** "ลดหย่อนภาษี = ต้องซื้อกองทุน/ประกันแพงๆ" → ค่าลดหย่อนพื้นฐานที่ได้ฟรีอยู่แล้ว (ส่วนตัว 60,000 + หักค่าใช้จ่าย 50% ไม่เกิน 100,000 + ประกันสังคม) เยอะกว่าที่คิด
- **ตัวเลขจริงไทย (ปีภาษี 2568–2569):**
  - ขั้นบันได: ยกเว้น 150,000 แรก → 5% / 10% / 15% / 20% / 25% / 30% / 35%
  - หักค่าใช้จ่ายเงินเดือน 50% แต่ไม่เกิน 100,000 · ค่าลดหย่อนส่วนตัว 60,000
  - RMF: ไม่เกิน 30% ของเงินได้ และไม่เกิน 500,000 (รวมกลุ่มเกษียณ)
  - Thai ESG: ไม่เกิน 30% และไม่เกิน 300,000 · **SSF ซื้อใหม่ลดหย่อนได้ถึงปีภาษี 2567 เท่านั้น — ปี 2568 เป็นต้นไปไม่มีแล้ว**
  - ประกันชีวิต + สุขภาพตนเอง รวมไม่เกิน 100,000 (สุขภาพตนเองไม่เกิน 25,000) · ประกันสุขภาพพ่อแม่ไม่เกิน 15,000
  - ยื่นภาษี ม.ค.–มี.ค. (ออนไลน์ผ่านเว็บกรมสรรพากรถึงต้น เม.ย.) — เงินเดือนอย่างเดียวใช้ ภ.ง.ด.91
- **3 จุดหลัก:** (1) รู้ก่อนว่าตัวเองอยู่ขั้นภาษีกี่ % → ทุก 1 บาทที่ลดหย่อนได้คืนกี่สตางค์ (2) ไล่ค่าลดหย่อนจากฟรี → ต้องจ่ายเงินซื้อ ซื้อเมื่อคุ้มเท่านั้น (3) ยื่นเอง 15 นาที + วางแผนล่วงหน้าไม่ใช่ซื้อรวบตอน ธ.ค.
- **กับดัก:** ซื้อ RMF/ประกันเกินความจำเป็นเพื่อ "ประหยัดภาษี" ทั้งที่เงินก้อนนั้นถูกล็อกยาว / แจ้งลดหย่อนกับ HR เกินจริง → ปลายปีโดนเรียกเก็บเพิ่ม
- **ลองทำเลย:** กรอกเว็บวางแผนภาษี ดูว่าปีนี้จะได้คืนหรือต้องจ่ายเพิ่ม แล้วค่อยตัดสินใจว่าต้องซื้ออะไรเพิ่มไหม
- **CTA:** เซฟ + แท็กเพื่อนที่ยังไม่เคยยื่นเอง
- **เชื่อมเครื่องมือ:** เว็บวางแผนรายได้ & ภาษี 2569

### บท 5 — การเลือกประกัน *(Ness เป็นตัวแทน — soft lead-gen)*
- **Hook:** "ประกันที่ดีที่สุดสำหรับคนเงินเดือน มักจะเป็นตัวที่ตัวแทนได้ค่าคอมน้อยที่สุด — และผมพูดในฐานะตัวแทนเอง"
- **ความเชื่อที่เถียง:** "ซื้อประกันไว้ = ได้ทั้งคุ้มครองทั้งออมทั้งลงทุน" → ประกันทำได้ดีอย่างเดียวคือ**โอนความเสี่ยงก้อนใหญ่ที่จ่ายเองไม่ไหว** ส่วนออม/ลงทุนมีเครื่องมือที่ดีกว่า
- **ตัวเลข/หลักคิด:**
  - ลำดับความจำเป็น: สุขภาพ/อุบัติเหตุ (ค่ารักษาหลักแสน–ล้าน) > ชีวิต (ถ้ามีคนพึ่งพารายได้) > อื่นๆ
  - ทุนประกันชีวิตที่พอ ≈ 3–5 เท่าของรายได้ต่อปี (ถ้ามีภาระ/คนต้องเลี้ยง) — ถ้าโสดไม่มีภาระ อาจไม่ต้องมี
  - เบี้ยประกันชีวิต+สุขภาพ ลดหย่อนได้รวมไม่เกิน 100,000 (เชื่อมบท 6)
  - ระวังประกันควบการลงทุน (unit-linked) / สะสมทรัพย์ — ค่าธรรมเนียมช่วงต้นสูง ผลตอบแทนจริงมักต่ำกว่าลงทุนกองทุนเอง
- **3 จุดหลัก:** (1) ประกันแก้ปัญหาอะไรได้จริง / อะไรที่ไม่ใช่หน้าที่ประกัน (2) ซื้อเท่าไรถึงพอ (คำนวณจากภาระจริง ไม่ใช่จากที่ตัวแทนเสนอ) (3) อ่านกรมธรรม์ตรงไหนก่อนเซ็น — ความคุ้มครอง, ข้อยกเว้น, เบี้ยหลังปีที่ 10
- **กับดัก:** ซื้อเพราะเกรงใจตัวแทน / ซื้อแบบผสมเพราะ "ได้เงินคืน" ทั้งที่เป้าหมายคือลงทุน
- **ลองทำเลย:** เขียนออกมาว่าถ้าป่วยหนัก/เกิดอุบัติเหตุ ใครเดือดร้อนบ้าง เท่าไร — นั่นคือช่องว่างที่ประกันต้องอุด
- **CTA (soft, consultative):** "ถ้าอยากให้ช่วยดูว่าที่มีอยู่พอหรือเกิน ทักมาคุยได้ ไม่ต้องซื้ออะไร" — ไม่ขายตรง
- **หมายเหตุ lead-gen:** พูดตรงข้ามผลประโยชน์ตัวเอง (เตือนเรื่อง unit-linked) = สร้าง trust → คนทักเอง

### บท 11 — ตั้งเป้าหมายการเงิน + ออกแบบการเงินส่วนบุคคล *(บทปิด / อาจตัดสั้นทำ ตอนที่ 0 ด้วย)*
- **Hook:** "คนส่วนใหญ่ตั้งเป้าเป็นตัวเลข ('อยากมีล้านนึง') แต่ไม่เคยถามว่าล้านนึงเอาไว้ทำอะไร — เป้าที่ดีเริ่มจากคำถามหลัง ไม่ใช่ตัวเลขหน้า"
- **ความเชื่อที่เถียง:** "ต้องรายได้เยอะก่อนถึงวางแผนได้" → การออกแบบการเงินคือการจัดลำดับ ไม่ใช่การมีเงินเหลือ
- **เนื้อหา:** ร้อยทุกบทเข้าด้วยกัน — ลำดับ: กระแสเงินสด (บท 1,4) → กันชน (บท 3) → ป้องกัน (บท 5) → ภาษี (บท 6) → ให้เงินโต (บท 8,9) → เป้าใหญ่ (บ้าน บท 10, เกษียณ)
  - พลังดอกเบี้ยทบต้น: ตัวอย่าง DCA เดือนละ 3,000 ที่ 7%/ปี 20 ปี ≈ 1.5 ล้าน (ใส่เงินจริง 720,000)
  - กฎ 4% / เกษียณต้องมีเท่าไร = ค่าใช้จ่ายต่อปี × 25
- **ลองทำเลย:** เขียนเป้าหมาย 3 ช่วง (1 ปี / 5 ปี / เกษียณ) + จำนวนเงิน + ทำไม
- **CTA:** "ปีหน้าเปิดไฟล์นี้กลับมาอ่าน แล้วเช็กว่าตัวเองมาถึงไหน" + ประกาศรวมเล่ม
