# ☀️ Weekend Lesson — วันอาทิตย์ที่ 10 สิงหาคม 2569

**🗓️ Phase 1 / Week 7: SQL — เขียน SELECT / WHERE / GROUP BY เองครั้งแรก**

> สัปดาห์ที่แล้วรู้จัก aggregate function (SUM/COUNT/AVG) แบบเดาจากตัวอย่างที่เว็บเตรียมให้ วันนี้ขยับอีกก้าว: เรียนรู้ GROUP BY (สรุปตัวเลข "แยกตามกลุ่ม") แล้ว **พิมพ์ query เองตั้งแต่บรรทัดแรก** ไม่ใช้ตัวอย่างสำเร็จรูปอีกต่อไป

---

## 📖 เรียนรู้อะไรวันนี้ (5 นาที)

ทบทวน: SUM/COUNT/AVG สรุปข้อมูล "ทั้งหมด" ให้เหลือเลขเดียว (เช่น ประชากรโลกรวมทั้งหมด)

วันนี้เพิ่ม 1 concept ที่ทำให้ SQL มีประโยชน์ขึ้นอีกระดับ:

**GROUP BY = สรุปตัวเลข แต่ "แยกตามกลุ่ม"** แทนที่จะได้เลขเดียวรวมทั้งหมด เราจะได้ตารางที่มี 1 แถวต่อ 1 กลุ่ม เช่น "แต่ละทวีปมีกี่ประเทศ" (ไม่ใช่ "โลกมีกี่ประเทศ")

เทียบกับ Pivot Table ที่เคยทำ (สัปดาห์ 1-2): ตอนลาก field เข้าช่อง **Rows** (เช่น "ทวีป") แล้วลาก field อีกอันเข้าช่อง **Values** (เช่น "นับจำนวนประเทศ") — นั่นคือ GROUP BY เป๊ะๆ แค่ Pivot Table ทำด้วยการลากเมาส์ ส่วน SQL ทำด้วยการพิมพ์ `GROUP BY ชื่อคอลัมน์`

โครงสร้างที่ใช้บ่อยที่สุดของ analyst:
```
SELECT คอลัมน์ที่จะแยกกลุ่ม, AGGREGATE(คอลัมน์ที่จะสรุป)
FROM ตาราง
WHERE เงื่อนไข (ถ้ามี)
GROUP BY คอลัมน์ที่จะแยกกลุ่ม
```

ทำไมต้องรู้: รายงานการเงินแทบทุกอันหน้าตาแบบนี้ — "ยอดขายแยกตามเดือน", "จำนวนลูกค้าแยกตามประเทศ", "กำไรแยกตามสาขา" ล้วนคือ GROUP BY ทั้งนั้น

## ⚡ ลองทำเลย (15 นาที) — พิมพ์เอง ไม่ใช้ตัวอย่างสำเร็จรูป

1. เปิด https://sqlzoo.net/wiki/SUM_and_COUNT (เว็บเดิมที่ใช้มา 2 สัปดาห์)
2. เลื่อนหาคำถาม **"For each continent show the continent and number of countries."**
3. **ลบ query ที่มีอยู่ในกล่องออกให้หมด** แล้วพิมพ์เองทีละบรรทัดตามโครงสร้างด้านบน:
   ```
   SELECT continent, COUNT(name)
   FROM world
   GROUP BY continent
   ```
4. กด **Submit** — เช็คว่าได้ผลลัพธ์เป็นตาราง 1 แถวต่อ 1 ทวีป (ไม่ใช่เลขเดียว)
5. หาคำถามถัดไป **"...with populations of at least 10 million"** — พิมพ์เองอีกครั้ง แต่คราวนี้เพิ่ม `WHERE population >= 10000000` เข้าไปเอง (วางไว้ระหว่าง FROM กับ GROUP BY) แล้ว Submit
6. สังเกต: ลำดับของ query คือ `SELECT → FROM → WHERE → GROUP BY` เสมอ ลองท่องลำดับนี้ให้คล่องปาก เพราะจะใช้ทุกครั้งที่เขียน SQL

จบแค่นี้ — สัปดาห์หน้า (Week 8) จะเขียน SELECT/WHERE/GROUP BY ครบชุดจากโจทย์ใหม่ที่ยังไม่เคยเห็น มาเช็คว่าจำ pattern ได้จริงไหม
