# system/ — ไฟล์อ้างอิงสำหรับเขียน Content (The Money Ness)

โฟลเดอร์นี้เก็บไฟล์อ้างอิงที่ Claude ต้องอ่านก่อนเขียน Content ทุกครั้ง
เก็บไว้ในนี้ (public repo) เพื่อให้ Claude อ่านได้ผ่าน GitHub โดยตรง
**ไม่ต้องเชื่อมต่อคอมพิวเตอร์ของ Ness ก็อ่านได้**

## ไฟล์ในนี้ (ต้นฉบับตัวจริงทั้งหมด ยกเว้นที่ระบุว่าเป็น mirror)
- `ness-profile.md` — ตัวตนและสไตล์ของ Ness
- `weekly-topics.md` — Layer + หัวข้อประจำสัปดาห์
- `style-guide.md` — Reel DNA, tone, โครงสร้าง, CTA rules, Gemini Image Brief format
- `content-calendar.md` — ปฏิทิน content ที่ทำไปแล้ว/กำลังทำ
- `fact-check-protocol.md` — กฎการ fact-check ตัวเลขก่อนตีพิมพ์
- `MASTER-WORKFLOW.md` — **mirror เท่านั้น** ต้นฉบับตัวจริงอยู่ที่ root ของ Claude Workspace บนเครื่อง Ness

## กติกาสำคัญ — กันไฟล์แยกกันสองชุด (เคยมีปัญหานี้กับ Google Drive)
ไฟล์ 5 ไฟล์แรกในนี้คือ**ต้นฉบับตัวจริงหนึ่งเดียว** ไม่มีสำเนาอื่นอีกแล้ว —
ไฟล์เดิมที่เคยอยู่ SHARED/ ถูกแทนที่ด้วยข้อความชี้มาที่นี่
แก้ไขที่ไฟล์ในโฟลเดอร์นี้เท่านั้น แล้ว commit + push ขึ้น GitHub —
ไม่ว่าจะแก้จากเครื่อง Ness (ผ่าน git) หรือแก้จาก Claude ทางไกล (ผ่าน GitHub API/connector)
ก็แก้ "ไฟล์เดียวกัน" ในประวัติ git เดียวกันเสมอ — ไม่มีทางแยกเป็นสองความจริงที่ขัดกันได้
ถ้าเครื่อง Ness ยัง pull ไม่ทัน ก็แค่ "ตามหลังอยู่" (behind) ไม่ใช่ "ข้อมูลคนละชุด"
