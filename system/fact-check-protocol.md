## หลักการ: ข้อมูลมี "อายุ" ต่างกัน

ข้อมูลบางอย่างไม่เปลี่ยน ข้อมูลบางอย่างเปลี่ยนทุกวัน Claude ต้องรู้ว่าอันไหนคืออันไหน

| ประเภท | ตัวอย่าง | ความเสี่ยง Outdated | วิธีตรวจ |
|--------|---------|-------------------|---------|
| 🔴 **สูง** — กฎหมาย/ภาษี | RMF วงเงิน, Thai ESG เงื่อนไข, อัตราภาษี | เปลี่ยนได้ทุกปี | ค้นเว็บ + ดูปีภาษีที่อ้างอิง |
| 🔴 **สูง** — ราคาตลาด | BTC ราคา, Gold ราคา, Exchange rate | เปลี่ยนทุกนาที | บอกวันที่ข้อมูลเสมอ |
| 🟡 **กลาง** — โครงสร้างผลิตภัณฑ์ | กองทุนไหนยังมีอยู่, ประเภท ETF | เปลี่ยนได้ตามนโยบาย | ค้นเว็บก่อน claim |
| 🟡 **กลาง** — ตัวเลขสถิติ | % retail trader ขาดทุน, Lightning volume | เปลี่ยนช้า แต่เปลี่ยน | ระบุปีที่มาของ stat |
| 🟢 **ต่ำ** — หลักการพื้นฐาน | Leverage คืออะไร, DCA ทำงานยังไง | แทบไม่เปลี่ยน | ไม่ต้องตรวจทุกครั้ง |

## Checklist ก่อน Publish

### สำหรับ Content โพสต์เพจ

- [ ] **ตัวเลขทุกตัว** มีแหล่งที่มาหรือวันที่อ้างอิงไหม?
- [ ] **กฎหมาย/ภาษี** ตรวจแล้วว่าใช้กับปีภาษีปัจจุบันไหม? (ไม่ใช่ข้อมูลปีก่อน)
- [ ] **ชื่อผลิตภัณฑ์** (กองทุน, บัญชี, สิทธิ์) ยังมีให้ใช้อยู่จริงไหม?
- [ ] **ราคาตลาด** มีบอกวันที่ไหม? ไม่มีวันที่ = ห้ามใช้

### สำหรับ Learning Brief (เนื้อหาเรียน)

- [ ] ข้อมูล 🔴 ทุกชิ้น — ค้น web ก่อนเขียนเสมอ
- [ ] ข้อมูล 🟡 — ระบุปีที่มา ถ้าไม่มีให้บอกว่า "ณ ช่วงเวลาที่เรียน"
- [ ] ข้อมูล 🟢 — เขียนได้เลย ไม่ต้องตรวจ

## วิธีใช้จริง — Claude ต้องทำก่อนเขียน

**Step 1 — Scan content ที่กำลังจะเขียน**
ระบุ data points ที่อยู่ใน category 🔴 และ 🟡

**Step 2 — ตรวจแต่ละข้อ**
```
🔴 กฎหมาย/ภาษี → ค้น web ทุกครั้ง ไม่มีข้อยกเว้น
🔴 ราคาตลาด → ค้น web หรือบอกว่าข้อมูล ณ วันที่ [วัน/เดือน/ปี]
🟡 โครงสร้างผลิตภัณฑ์ → ค้น web ถ้าไม่แน่ใจ
```

**Step 3 — ติด Flag บน content ที่ยังไม่ verify**
ถ้ายังไม่ได้ตรวจ ให้ใส่ `⚠️ [ยังไม่ verify — ตรวจก่อน publish]` ไว้ก่อน

**Step 4 — บอก Ness เสมอว่าอะไร verified และอะไรยังไม่ verified**

## Red Flags — หยุดทันทีถ้าเจอสิ่งเหล่านี้

🚫 Claude เขียนตัวเลขภาษีโดยไม่ได้ค้น web ในปีนั้น
🚫 ชื่อผลิตภัณฑ์ที่ Claude "รู้มาแต่ก่อน" โดยไม่ verify ว่ายังมีอยู่
🚫 ราคาตลาดที่ไม่มีวันที่กำกับ
🚫 กฎหมายที่อ้างอิงโดยไม่บอกปีที่มีผลบังคับ
