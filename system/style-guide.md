### 🎯 Ness Reel DNA (อัปเดต 23 มิ.ย. 2026)

**สไตล์การเล่า:** Monologue ในหัว — พูดความคิดออกมาตรงๆ ไม่ใช่การสอน
- เปิดด้วย internal thought: "ผมนั่งคิดอยู่ว่า..." / "มีเรื่องนึงที่ผมเพิ่งสังเกตเห็น..."
- ไม่ใช่ครูสอน ไม่ใช่ expert — เป็นคนที่กำลังแชร์สิ่งที่คิดอยู่จริงๆ

**Trigger ที่ทำให้อยากพูด (เลือก 1 อย่าง):**
- เจอข้อมูล/ข้อเท็จจริงที่น่าสนใจ และอยากแชร์
- เห็นความเชื่อที่คนส่วนใหญ่มี แล้วอยากเถียง

**ทำไมคนหยุดดู:** Honest + ข้อมูลที่น่าสนใจ — ไม่ใช่ entertainment แต่คือ authenticity และ substance

**On camera:** นั่งนิ่งๆ — ไม่ต้องเดิน ไม่ต้องวุ่นวาย production สูง

**สไตล์ที่ชอบ:**
- ✅ Monologue ต่อเนื่อง ไม่ jump cut
- ✅ Hook 1 ประโยคแรก — honest ไม่ใช่ตื่นเต้นเกินจริง
- ✅ มีตัวเลขจริงและผลลัพธ์จริง
- ✅ จบแบบ Loop

**สไตล์ที่ไม่ชอบ:**
- ❌ Jump cut เร็วๆ
- ❌ Hook กดดัน เร่งรัดเกินไป
- ❌ เล่นอารมณ์อย่างเดียว ไม่มี value กลับบ้าน
- ❌ CTA แบบ hard sell

**โครงสร้าง Reel ของ Ness:**
1. Hook (1 ประโยค) — ความคิด/ข้อมูล/ความเชื่อที่อยากเถียง
2. Monologue ไหลต่อเนื่อง — เล่าจากมุมมองตัวเอง รวมตัวเลขจริง
3. จบด้วย loop หรือคำถามเปิดให้คนนำกลับไปคิด

**Loop Ending มี 2 แบบที่ผ่านการ approve แล้ว:**
- แบบ 1: จบด้วยคำถามที่ต้นคลิปตอบ → "แล้วถ้าวันนี้คุณกำลังถามตัวเองว่า — [คำถามเดียวกับต้นคลิป]?"
- แบบ 2: จบด้วยประโยคค้างกลางอากาศ → "เพราะฉะนั้นทุกครั้งที่มีคนถามฉัน —" แล้วคลิปวน

**CTA 3 แบบ (เลือกใช้ตาม context — embed ในประโยคสุดท้ายเสมอ ไม่แยกออกมา):**
- แบบ A "Invite เถียง": "ผมคิดแบบนี้นะ ใครเห็นต่างคอมเม้นได้เลย อยากรู้มุมอื่นเหมือนกัน" → ใช้เมื่อ content เป็นการเถียงความเชื่อคนส่วนใหญ่ — สร้าง comment สูงสุด
- แบบ B "Save พร้อมเหตุผล": "Save ไว้ก่อนก็ได้ เผื่อวันที่ [สถานการณ์ที่เกี่ยวข้อง] จะได้กลับมาอ่านตอนนั้น" → ใช้เมื่อ content เป็นข้อมูลที่มีประโยชน์ในอนาคต
- แบบ C "คำถามปิด": จบด้วยคำถามที่คนเอากลับไปคิดต่อเอง → ใช้เมื่ออยากให้คนสะท้อนตัวเอง เหมาะกับ loop ending

**Framework เลือก Loop vs CTA:**

ถามคำถามนี้ก่อน: "คนดูจบแล้วรู้สึกอะไร?"

→ อยากดูอีกรอบ = **จบด้วย Loop**
→ อยากพูดอะไรบางอย่าง = **จบด้วย CTA แบบ A (comment)**
→ อยากเก็บไว้ใช้ทีหลัง = **จบด้วย CTA แบบ B (save)**

| Content ประเภท | จบแบบไหน | เหตุผล |
|---|---|---|
| เล่าเรื่อง / storytelling ที่ดึงอารมณ์ | Loop | คนอยากดูซ้ำเพื่อจับรายละเอียด |
| เถียงความเชื่อที่คนส่วนใหญ่มี | CTA A (comment) | คนมีความเห็นอยู่แล้ว อยากแสดงออก |
| ข้อมูลที่มีประโยชน์ในอนาคต (how-to, เตือนใจ) | CTA B (save) | คนรู้ว่าจะต้องการมันทีหลัง |
| จบด้วยคำถามที่คนอยากตอบ | CTA C หรือ Loop | ขึ้นอยู่กับว่าคำถามนั้น invite debate หรือแค่ให้คิด |

หมายเหตุ: Loop และ CTA ใช้พร้อมกันไม่ได้ — ต้องเลือก 1 อย่างต่อคลิป

## 🖼️ CONTENT FORMAT — SINGLE IMAGE POST

โครงสร้างมี 3 ส่วนเสมอ:

**1. Text บนรูป**
- หัวข้อหลัก (font ใหญ่ bold อ่านได้ตั้งแต่ scroll ผ่าน)
- Sub text (ขยายความหัวข้อ 1 บรรทัด)
- Branding: The Money Ness

**2. Caption**
- เปิดด้วย context หรือ personal story สั้นๆ ว่าทำไมเรื่องนี้ถึงสำคัญ
- อธิบายเนื้อหาหลักแบบละเอียด หลาย paragraph
- มีตัวเลขจริงประกอบ
- โยงกับชีวิต Sales Rep / มนุษย์เงินเดือน
- จบด้วย CTA (คอมเม้น / save)
- ความยาว: substantial — ไม่ใช่แค่ 3-4 บรรทัด ต้องให้คนได้ value จากการอ่าน caption อย่างเดียว
- **[เพิ่ม 8 ก.ย. 2569]** ปิดท้าย caption ด้วย Hashtag ที่เกี่ยวข้องอย่างน้อย 3-5 อันเสมอ (ผสมไทย/อังกฤษได้ เน้นคำที่คนค้นหาจริง เช่น ชื่อเพจ + หมวดหมู่เนื้อหา) — ใช้ทั้งเวอร์ชัน FB และ IG

**3. Design Direction**
- สี / font / layout สำหรับนักออกแบบ

> หมายเหตุ: ถ้าโพสต์มี Quiz ให้ใส่ท้าย caption เสมอ ไม่ใช่แทนที่ caption  
> รูปแบบรวม = สอนก่อน (caption ยาว) + Quiz ตอนท้าย (drive comment)

> **[อัปเดต 4 ก.ย. 2026]** ทุก Single Image post ต้องมี caption 2 เวอร์ชันเสมอ — Facebook (ยาวเต็ม ไม่จำกัด) กับ Instagram (ย่อ ≤2,200 ตัวอักษร ตามลิมิตแพลตฟอร์ม) ดูรายละเอียดวิธีย่อใน Decisions & Preferences Log ท้ายไฟล์นี้

## 🎨 GEMINI IMAGE BRIEF FORMAT (Single Image Post)

### 🧭 เกณฑ์เลือกสัญลักษณ์/ฉาก — คิดก่อนเขียนบรีฟทุกครั้ง (เพิ่ม 8 ก.ย. 2569)

ก่อนสรุปว่าจะใช้วัตถุ/ฉากอะไรเป็น Hero ของภาพ ให้ Claude คิดออกมาเองจากเนื้อหา/อารมณ์หลักของโพสต์นั้นๆ ก่อนเสมอ ไม่ต้องรอให้ Ness ระบุคอนเซ็ปต์มาให้ทุกครั้ง

**Test ที่ต้องผ่านก่อนสรุปบรีฟ:** ถ้าคนเห็นภาพนี้ครั้งแรกโดยไม่มีแคปชั่นกำกับ จะเข้าใจอารมณ์/เรื่องที่สื่อทันทีไหม? ถ้าคำตอบคือ "ต้องอธิบายเพิ่ม" หรือ "ต้องตีความ" → ตัดคอนเซ็ปต์นั้นทิ้ง แล้วหาฉากที่เล่าเรื่องได้เองแทน

**หลักการเลือก:**
- เลี่ยงสัญลักษณ์นามธรรมเดี่ยวๆ ที่ต้องตีความ (เช่น กุญแจ = เป้าหมาย/ความฝัน, ตาชั่ง = สมดุล) — คนดูมักงงว่าทำไมต้องเป็นวัตถุนั้น
- เลือกฉากที่มีคน + สถานการณ์ที่เล่าเรื่องได้เองแบบสากล (universal visual metaphor) เช่น คนมองขึ้นไปหาสิ่งที่อยากได้ที่อยู่ไกล/สูง/ยาก, คนแบกภาระ, คนยืนอยู่กลางทางแยก ฯลฯ — สื่อสารตรงและเร็วกว่าสัญลักษณ์วัตถุเดี่ยว
- ตัวอย่างเปรียบเทียบจริง: "กุญแจถูกกองเงินทับ" (ต้องตีความ, สื่อสารไม่เข้าใจ) เทียบกับ "คนมองขึ้นภูเขาแห่งความมั่นคง มีบ้าน/รถอยู่ไกลลิบบนยอด" (เข้าใจทันที) — โพสต์ 8 ก.ย. 2569 เปลี่ยนจากแบบแรกเป็นแบบหลังแล้ว Ness ชอบมากบอกว่า "อยากได้แบบนี้ตั้งแต่แรก"
- ยังต้องคุมสไตล์ภาพให้อยู่ในกรอบ Conceptual Realistic / Surreal Metaphor เหมือนเดิม (ดูหัวข้อ IMAGE STYLE DIRECTION ด้านล่าง) แค่เปลี่ยนตรรกะการเลือก "อะไรจะเป็น Hero ของฉาก" ให้ยึดความเข้าใจง่ายเป็นหลัก ไม่ใช่ความสวย/แปลกใหม่อย่างเดียว

### 🎯 IMAGE STYLE DIRECTION (อัปเดต 23 มิ.ย. 2026)

**สไตล์หลักที่ใช้: Conceptual Realistic / Surreal Metaphor**
ไม่ใช่ภาพ Sci-Fi / Future Tech / Fantasy — แต่เป็นภาพที่พื้นผิวดูสมจริง แต่สถานการณ์เป็นสัญลักษณ์เชิงแนวคิด

**คำ keyword ที่ควรใช้ใน Image Prompt:**
- สไตล์ภาพ: `Conceptual Still Life`, `High-concept Editorial Illustration`, `Photorealistic render`, `Miniature Diorama Style`
- แสง: `Cinematic Lighting`, `Chiaroscuro`, `Moody`, `Shallow depth of field`
- ความเหนือจริง: `Surreal Juxtaposition`, `Metaphorical visualization`, `Impossible object`
- พื้นผิว: `Gritty textures`, `Hyper-realistic 3D render`, `Photorealistic`

**คำที่ต้องหลีกเลี่ยง:** `Sci-Fi`, `Futuristic`, `Hi-tech`, `Fantasy`, `Glowing tech elements`

**โครงสร้าง Image Prompt ที่ดี:**
`[สไตล์ภาพ + แสง] → [วัตถุหลัก + สถานการณ์เหนือจริง] → [พื้นผิวและวัสดุที่ต้องการ] → [อารมณ์ + โทนสี] → [ข้อห้าม]`

### 🔥 ทางเลือกที่ 2: Symbolic Aggressive Object Photography Formula (เพิ่ม 4 ก.ย. 2026)

ใช้เมื่อ topic ต้องการความรู้สึกดรามาติก กวนๆ หรือสะเทือนใจกว่าโทน moody เรียบๆ ด้านบน — Ness ทดลองปรับบรีฟเองจนได้ภาพที่ถูกใจ (โพสต์เบี้ยประกันสุขภาพ 4 ก.ย. 2026 อ้างอิงสไตล์เพจ Money Buffalo) แล้วสรุปสูตรกลับมาให้ใช้ซ้ำได้

**สูตร Prompt (Template — เติมส่วน [ ] ตาม topic):**
1. "ภาพถ่ายระยะใกล้ (Macro photography) ของ [วัตถุจริงที่ต้องการ] วางอยู่บน [พื้นผิว เช่น โต๊ะไม้เนื้อชัด] จัดองค์ประกอบและสัดส่วนวัตถุแบบ 'ตัดแปะเชิงสัญลักษณ์' (Symbolic and Aggressive/Forceful Object Scaling)"
2. "แสง: จัดจ้านและสร้างดราม่า (Aggressive Directional Lighting) สร้างเงามืดคมชัด (High-contrast Chiaroscuro) ตัดกับวัตถุที่คมชัดและสีสันจัดจ้าน (Bright, saturated colors) ไม่มัว"
3. ระบุรายละเอียดวัตถุ/การจัดวางเฉพาะเจาะจงสำหรับ topic นั้นๆ ต่อท้าย

**ทำไมสูตรนี้ได้ผล:**
- `Macro photography` + วัตถุจริง → บังคับให้เป็นภาพถ่ายวัตถุจริง ไม่ใช่ CGI/ภาพวาด/การ์ตูน

- `Aggressive Directional Lighting` + `High-contrast chiaroscuro` → สร้างความดรามาติก
- `Bright, saturated colors` → กันไม่ให้ภาพมัว/ทึบเกินไปทั้งที่แสงจัด (ต่างจาก Chiaroscuro แบบมืดหม่นในทางเลือกที่ 1 ด้านบน)

### 🛡️ ทางเลือกที่ 3: Symbolic Hero vs Villain Object Formula (เพิ่ม 6 ก.ย. 2569, ปรับให้ใช้ได้ทุกแนว 6 ก.ย. 2569)

**สไตล์นี้ใช้ได้กับแทบทุกแนว Content ไม่ได้จำกัดแค่หัวข้อป้องกันความเสี่ยงเท่านั้น** — Ness ชอบสไตล์นี้เป็นการส่วนตัวและอยากใช้เป็นทางเลือกหลักได้กับเนื้อหาหลากหลายประเภท (เปรียบเทียบทางเลือก, เตือนความเสี่ยง, สร้างแรงจูงใจให้ตัดสินใจ, โชว์ผลลัพธ์ระยะยาว ฯลฯ) จุดเด่นคือการมี **วัตถุตัวเอก (Hero Object)** ที่สื่อถึงสิ่งที่อยากให้คนดูเห็นแล้ว "อยากได้/เห็นด้วย" เทียบกับ **วัตถุตัวร้าย (Villain Object)** ที่สื่อถึงปัญหา/ทางเลือกที่แย่กว่า วางประชันกันในภาพเดียว — ต่อยอดจากทางเลือกที่ 2 (Macro/สมจริง) แต่เพิ่มโครงเรื่องเชิงสัญลักษณ์แบบ "ใครชนะใคร" ชัดเจนกว่า (Ness ทดลองปรับบรีฟเองร่วมกับ Gemini จนได้ภาพที่ถูกใจ อ้างอิงโพสต์เช่า+ลงทุนเทียบซื้อบ้าน 4 ล้าน 6 ก.ย. 2569)

> **หมายเหตุ:** เพราะเป็นสไตล์ที่ Ness ชอบเป็นพิเศษ ตั้งแต่นี้ไปให้ลองเสนอสไตล์นี้เป็นหนึ่งในตัวเลือกเริ่มต้นของ Gemini Image Brief เสมอ (ควบคู่กับสไตล์ที่ 1 หรือ 2 แล้วแต่ความเหมาะสมของหัวข้อ) ไม่ต้องรอให้ Ness สั่งเจาะจงว่าอยากได้แนวป้องกัน/สัญลักษณ์เท่านั้นก่อนถึงจะเสนอ

**สูตร Prompt (Template — เติมส่วน [ ] ตาม topic):**
1. **วัตถุตัวเอก (Hero Object)** — สิ่งที่สื่อถึง "ทางออก/ชัยชนะ/สิ่งที่ถูกต้อง" ของหัวข้อ (ไม่จำกัดว่าต้องเป็นการป้องกันความเสี่ยง) เช่น โล่จากเหรียญ+ธนบัตร (ป้องกันความเสี่ยงการเงิน), กำแพงเหรียญ (สะสมเงิน), บันไดเหรียญ (ไต่ระดับความมั่งคั่ง), เข็มทิศทองคำ (ตัดสินใจถูกทาง), ต้นไม้เหรียญที่ผลิดอกออกผล (ผลตอบแทนจากการลงทุน) — เป็นวัตถุจริง ไม่ใช่ CGI
2. **วัตถุตัวร้าย (Villain Object)** — สิ่งที่สื่อถึง "ปัญหา/ทางเลือกที่แย่กว่า/สิ่งที่แพ้" ของหัวข้อ วางไว้ด้านหลังหรือถูกวัตถุตัวเอกบดบัง/ครอบงำ เช่น บ้านจำลองที่พังทรุด (หนี้บ้าน/การตัดสินใจผิด), นาฬิกาทรายที่ทรายหมด (หมดเวลา/โอกาสที่เสียไป), กระเป๋าเงินที่มีรูรั่ว (รายจ่ายที่รั่วไหล)
3. **องค์ประกอบเสริม (ไม่บังคับ)** — สัญลักษณ์ "ภัยที่ถูกเอาชนะแล้ว" เช่น กับดักหักที่พื้นหน้าภาพ พร้อมโซ่ขาด เพื่อเพิ่มดราม่าว่าอันตรายผ่านไปแล้ว
4. แสง: Cinematic chiaroscuro, low-angle directional light จากด้านเดียว, shallow depth of field ให้วัตถุตัวเอกคมชัดที่สุด ส่วนหน้า/หลังเบลอ
5. สไตล์ภาพ: Photorealistic macro/product-style photography เท่านั้น ห้าม CGI/การ์ตูน/3D animated/Sci-Fi

**เทคนิคล็อกสัดส่วนภาพเมื่อขอ aspect ratio ที่ไม่ใช่ 4:5 มาตรฐาน (สำคัญ — ป้องกันบั๊กที่เจอจริง):**
- ถ้า Ness ขอสัดส่วนอื่น (เช่น แนวตั้ง 3:4) ให้เขียนกำกับ **ทั้งต้นพรอมต์และท้ายพรอมต์** ว่าเป็นแนวตั้ง/portrait พร้อมย้ำว่า "taller than it is wide" ไม่ใช่แค่พิมพ์ตัวเลขอัตราส่วนเฉยๆ
- **บั๊กที่เจอจริง:** เขียนแค่ "vertical 4:3" แล้ว Gemini ตีความเป็นแนวนอน เพราะค่ามาตรฐานของ "4:3" คือ กว้าง:สูง (แนวนอน) — ถ้าต้องการแนวตั้งจริงๆ ให้เขียนเป็น **"3:4"** (กว้าง:สูง ที่สูงกว่ากว้าง) แทน อย่าเขียนกลับด้าน
- ระบุสัดส่วนพื้นที่ฉาก/พื้นที่ดำเป็น **เปอร์เซ็นต์ตัวเลขชัดเจน** (เช่น ฉาก 55-60% บน / พื้นที่ดำ 40-45% ล่าง) แทนคำกว้างๆ อย่าง "roughly two-thirds" — กันปัญหาพื้นที่ดำแคบเกินไปจนใส่ข้อความ 3 บรรทัดไม่พอ

**ค่าเริ่มต้น (บังคับตั้งแต่ 8 ก.ย. 2569): ไม่มีข้อความในภาพเลย** — ทุกบรีฟต้องสั่งพรอมต์ปล่อยพื้นที่สีดำว่างเปล่าจริงๆ (ไม่มีคำ/ตัวเลข/โลโก้ใดๆ ในพรอมต์) แล้วใส่ข้อความภาษาไทย 3 บรรทัดไว้แยกต่างหากเป็น reference ให้ Ness พิมพ์เองใน Canva ไม่ใส่ในพรอมต์ Gemini (เหตุผล: Gemini พิมพ์ไทยมั่วเสมอ — ดู Decision Log 6 ก.ย. และ 8 ก.ย. 2569) ยกเว้น Ness สั่งเจาะจงว่าอยากให้ Gemini ลองใส่ข้อความเองเป็นกรณีพิเศษ

**กฎความปลอดภัยเรื่องธนบัตรไทย (ถาวร ใช้ทุกบรีฟที่มีธนบัตร/เหรียญไทยในภาพ):**
- ธนบัตรไทยทุกใบมีพระบรมฉายาลักษณ์ ห้ามสั่งให้ AI render ใบหน้าบนธนบัตรให้ชัดเจน/จดจำได้ — ให้กำกับว่า "keep any figure on the notes soft, abstracted, or out of focus" เสมอ โดยเฉพาะฉากที่มีของแตกหัก/กับดัก/ความพ่ายแพ้อยู่ใกล้ๆ (เสี่ยงตีความไม่เหมาะสมทางกฎหมาย/วัฒนธรรม)
- หมายเหตุจากการใช้จริง: แม้กำกับไว้แล้ว AI บางครั้งยัง render ใบหน้าชัดกว่าที่ตั้งใจ — แนะนำให้ Ness เช็คภาพที่ได้ก่อนโพสต์เสมอ ถ้าใบหน้ายังชัดเกินไป ให้ครอป/เบลอเพิ่มก่อนใช้จริง

  2. **Instagram version** — ย่อจากเวอร์ชัน Facebook ให้เหลือ ≤2,200 ตัวอักษร โดยตัดคำฟุ่มเฟือย/ประโยคซ้ำออก แต่ต้องคงประเด็นหลักและการอ้างอิงเชิงวิชาการ (ชื่อคน/ปี/หนังสือ) ไว้ครบ ไม่ตัดเนื้อหาเชิงลึกทิ้งทั้งหมด — เป็นการย่อ ไม่ใช่การตัดทอน
- วิธีเช็คก่อนส่ง: count ตัวอักษรจริงด้วยโค้ด (นับ character ไม่ใช่ word) ก่อนยืนยันว่าอยู่ในลิมิต เผื่อ margin ไว้สัก 100-200 ตัวอักษรเสมอ ไม่ชนขอบพอดี 2,200

**[4 ก.ย. 2026 — Symbolic Aggressive Object Photography Formula]**
- เพิ่มทางเลือกที่ 2 สำหรับ Gemini Image Brief: สูตร Macro Photography + Symbolic/Aggressive Object Scaling + Aggressive Directional Lighting + Bright saturated colors (รายละเอียดเต็มอยู่ในหัวข้อ "GEMINI IMAGE BRIEF FORMAT" ด้านบน)
- ใช้เมื่อ Ness อยากได้ภาพที่ดรามาติก/กวนๆ กว่าโทน Chiaroscuro มืดหม่นแบบเดิม — มาจากการที่ Ness ทดลองปรับบรีฟเองจนได้ภาพถูกใจ (อ้างอิงสไตล์เพจ Money Buffalo) แล้วสรุปสูตรกลับมาให้บันทึกไว้ใช้ซ้ำ
- Process ที่เกิดขึ้นจริงกับโพสต์เบี้ยประกันสุขภาพ (4 ก.ย. 2026): เริ่มจากฉากหมอตรวจคนไข้ (มืด/ดุ) → ปรับเป็นสีสด/กวนๆ (ออกมาเป็นการ์ตูน 3D) → บังคับ photorealistic คนจริง (สีสดเกิน) → ลดสีลง (ดูสมจริงแต่ยังไม่ aggressive) → เปลี่ยนเป็นวัตถุจริงแบบ macro (ไม่มีคน) → Ness ปรับเองจนได้สูตรสุดท้าย — บทเรียน: ถ้า topic ต้องการความรู้สึก "ดุ/สะเทือนใจ" ให้เริ่มจากสูตรทางเลือกที่ 2 นี้เลย ไม่ต้องไล่ปรับทีละสเต็ปแบบนี้อีก

**[16 ส.ค. 2026 — Gemini Brief: บั๊กพิมพ์ชื่อสีเป็นข้อความจริง]**

- **แก้แล้ว:** เขียนเป็น prompt ก้อนเดียวรวด (ไม่แยกข้อ 1/2/3) ระบุสีด้วย hex code ต่อท้ายคำที่ต้องการ ("render '5-10%' in neon green color (#39FF14)") และปิดท้ายด้วยประโยคบังคับเสมอ: *"Do NOT print the words 'neon green', 'vibrant orange', or any color name anywhere in the image — those are styling instructions only, never literal text content."*

- พบและแก้บั๊ก: เขียน aspect ratio แบบ "vertical 4:3" แล้ว Gemini ตีความเป็นแนวนอน เพราะ "4:3" มาตรฐานคือกว้าง:สูง — แก้โดยเขียนเป็น "3:4" ตรงๆ พร้อมกำกับคำว่าแนวตั้ง/portrait ทั้งต้นและท้ายพรอมต์เสมอเมื่อขอสัดส่วนนอกเหนือจาก 4:5 มาตรฐาน
- เพิ่มกฎถาวร: ถ้ามีธนบัตร/เหรียญไทยในภาพ ต้องสั่งให้ AI เบลอ/abstract ใบหน้าบนธนบัตรเสมอ (พระบรมฉายาลักษณ์ + ความเสี่ยงทางกฎหมาย/วัฒนธรรม) และให้ Ness เช็คภาพก่อนโพสต์จริงทุกครั้ง
- Process ที่เกิดขึ้นจริง: Ness ปรับบรีฟเองร่วมกับ Gemini จนได้คอนเซ็ปต์ "โล่เงินปะทะบ้านพัง" → ลองครั้งแรกพื้นที่ดำแคบเกินไป → แก้เป็นระบุ % ชัดเจน (ฉาก 55-60% / ดำ 40-45%) → ลองอีกครั้งภาพออกมาแนวนอนเพราะบั๊ก aspect ratio → แก้เป็น "3:4" พร้อมกำกับซ้ำ → ได้ภาพที่ Ness ใช้จริง (`post-2026-09-05-rent-invest-breakeven-vs-4m-house.md`)
- **[อัปเดตย่อย เดียวกัน 6 ก.ย. 2026]** Ness แจ้งว่าไม่ได้อยากให้สูตรนี้จำกัดแค่ topic เรื่องป้องกันความเสี่ยงเท่านั้น แต่อยากใช้เป็นสไตล์หลักได้กับ Content แทบทุกแนว เพราะเป็นสไตล์ที่ชอบเป็นการส่วนตัว (เน้น Hero object เชิงสัญลักษณ์ + กฎความปลอดภัยธนบัตรไทย) — แก้ชื่อและคำอธิบายในหัวข้อ "ทางเลือกที่ 3" ด้านบนให้เปิดกว้างขึ้น และเพิ่มหมายเหตุให้เสนอสไตล์นี้เป็นตัวเลือกเริ่มต้นเสมอ ไม่ต้องรอให้สั่งเจาะจง

- **สรุป recipe มาตรฐานไว้ในหัวข้อ "CONTENT FORMAT — QUOTE / PHILOSOPHY IMAGE" → ✅ Recipe ที่ใช้จริง** — ใช้อ้างอิงทุกครั้งที่ทำ format นี้ต่อจากนี้
- Key decisions: (1) เลย์เอาต์ **ข้อความบน / ภาพลายเส้นล่าง** (2) Gemini ทำเฉพาะภาพลายเส้น one-line ไม่มีข้อความ/กรอบ (3) Ness ประกอบข้อความ + กรอบ + ฟุตเตอร์เองใน Canva — Claude ทำ mockup HTML อ้างอิงให้ (4) palette ดำ/ขาวอุ่น #F1EEE7/เทา #8C8C86 (5) ฟอนต์ Anuphan Bold + Light
- บทเรียน: อย่าสั่ง Gemini ใส่ข้อความไทย (มั่วเสมอ) หรือวาดกรอบ (แตกเสมอ) — 2 อย่างนี้ทำใน Canva เท่านั้น
- Process จริง: Claude ลองทำภาพเองเป็น SVG (stick figure) ก่อน → Ness ชอบ one-line art จาก Gemini มากกว่า → Claude ลองประกอบข้อความให้เป็น HTML/PNG → Ness ขอเอาไปทำเองใน Canva → บันทึกเป็นสไตล์

- Ness สังเกตว่า Gemini Image Brief หลักของ Single Image Post (หัวข้อ GEMINI IMAGE BRIEF FORMAT ด้านบน) ยังสั่งให้ Gemini render ข้อความไทย+สีเข้าไปในภาพอยู่ ทั้งที่บทเรียนจาก Quote/Philosophy Image (6 ก.ย. 2569) สรุปไว้แล้วว่า Gemini พิมพ์ไทยมั่วเสมอ — เป็น gap ที่อัปเดตแค่ format เดียวไม่ครบทั้งระบบ

- ข้อยกเว้น: ถ้า Ness สั่งเจาะจงอยากลองให้ Gemini ใส่ข้อความเอง ทำได้เป็นกรณีพิเศษ แต่ไม่ใช่ default อีกต่อไป

**[8 ก.ย. 2569 — เพิ่มเกณฑ์เลือกสัญลักษณ์/ฉากสำหรับ Gemini Image Brief]**
- ที่มา: โพสต์นี้เริ่มจากคอนเซ็ปต์ "ลูกกุญแจถูกกองเงินทับ" (ทางเลือกที่ 3) แล้ว Ness สั่งเปลี่ยนเป็น "คนมองขึ้นภูเขาแห่งความมั่นคง มีบ้าน/รถ/อิสรภาพอยู่บนยอด" ผลออกมา Ness ชอบมากกว่ามาก บอกว่า "อยากได้แบบนี้ตั้งแต่แรก"
- Ness ชี้ปัญหา: ไม่ใช่แค่อยากได้สูตรภูเขาไว้ใช้ซ้ำ แต่อยากให้ Claude **คิดคอนเซ็ปต์ภาพที่เข้าใจง่ายออกมาเองจากเนื้อหา** โดยไม่ต้องรอ Ness ระบุละเอียดทุกครั้ง — ปัญหาของกุญแจคือเป็นสัญลักษณ์ที่ต้องตีความ ไม่สื่อสารตรง
- **แก้แล้ว:** เพิ่มหัวข้อ "เกณฑ์เลือกสัญลักษณ์/ฉาก" เป็นเกณฑ์ถาวรต้นๆ ของ GEMINI IMAGE BRIEF FORMAT (ก่อนหัวข้อ IMAGE STYLE DIRECTION ด้านบน) ใช้ readability test เป็นตัวคัดกรองก่อนสรุปบรีฟทุกครั้ง ไม่ใช่การล็อกสูตรตายตัว

**[14 ก.ย. 2569 — เกณฑ์ readability test สำหรับภาพเปรียบเทียบตัวเลข/มูลค่า (multi-line comparison)]**
- ที่มา: บรีฟภาพโพสต์ "ค่าธรรมเนียมกองทุน 1%" ขอเปลี่ยนจากวัตถุเดี่ยว (ก๊อกน้ำหยดเหรียญ) เป็น "กราฟเส้น 3 เส้นเปรียบเทียบมูลค่า" — ทำผิดพลาด 2 รอบก่อนได้ภาพที่ Ness บอกว่า "ดี":
  1. รอบแรก: ใช้ "เส้นแสง 3 เส้น" นามธรรม (thread of light) — ผลออกมาเห็นแค่ 2 เส้นไขว้กันเป็น X ไม่มีจุดเริ่มร่วม อ่านไม่ออกว่าเป็นกราฟเปรียบเทียบ
  2. รอบสอง: เพิ่มเส้นฐาน (baseline) + บังคับให้ทั้ง 3 เส้นเริ่มจากจุดเดียวกันแล้วห้ามไขว้กันอีก — อ่านออกว่าเป็นกราฟ 3 เส้นแล้ว แต่เส้นกลาง/เส้นล่างสียังเหมือนกัน (เทา/เงินทั้งคู่) แยกไม่ออกว่าเส้นไหนคือมูลค่าจริง เส้นไหนคือค่าธรรมเนียมที่หาย
  3. รอบสาม: Ness ขอให้ "สื่อสารเรื่องเงิน/มูลค่า" เข้าไปในภาพเพิ่ม — เปลี่ยนจากเส้นแสงนามธรรมเป็น **สายเหรียญทองคำจริงๆ ร้อยต่อกัน** (เส้นบน=เหรียญอัดแน่น, เส้นกลาง=เหรียญห่างขึ้น/หม่นกว่าแต่ยังโทนทอง, เส้นล่าง=เหรียญทองแดง/สนิทกระจัดกระจาย) + ใช้ความหนาแน่นของเหรียญสื่อปริมาณเงินไปในตัว → Ness confirm ว่าดีแล้ว
- **บทเรียนถาวร (เพิ่มเข้ากฎ "เกณฑ์เลือกสัญลักษณ์/ฉาก" ด้านบน):** เวลาโจทย์เป็นภาพ "เปรียบเทียบตัวเลข/มูลค่า" (กราฟ, สัดส่วน, ก่อน-หลัง) ต้องผ่าน 3 เช็คนี้ก่อนส่งบรีฟรอบแรกเสมอ ไม่ต้องรอ Ness ทักท้วงแล้วค่อยแก้ทีละรอบแบบนี้อีก:
  1. **จุดเริ่มร่วม + ห้ามไขว้กัน** — ถ้ามีเส้น/แท่งหลายเส้นเปรียบเทียบกัน ต้องระบุจุดเริ่มต้นร่วมกันชัดเจน (หรือ baseline อ้างอิง) แล้วสั่งห้ามไขว้/ชนกันหลังแยกออกจากกัน ไม่งั้น AI มักวาดไขว้กันมั่วจนอ่านไม่ออกว่าเส้นไหนคือเส้นไหน
  2. **แยกด้วยสี ไม่ใช่แค่ความสูง/ความชัน** — แต่ละเส้น/ค่าที่ความหมายต่างกันต้องมีโทนสีต่างกันชัดเจน (เช่น ทองสว่าง = ดี/มาก, แดงสนิท/ทองแดงหมอง = สูญเสีย/น้อย) ห้ามปล่อยให้สองเส้นที่ความหมายต่างกันมีสีเดียวกันแล้วให้คนแยกจากความสูงอย่างเดียว
  3. **ใช้วัตถุที่สื่อ "เงิน" ตรงๆ แทนสัญลักษณ์นามธรรม** — ถ้าเนื้อหาเกี่ยวกับมูลค่า/เงิน ให้เริ่มต้นด้วยวัตถุที่เป็นเงินจริงๆ (เหรียญ/ธนบัตร/แท่งทอง ฯลฯ) แทนเส้นแสง/ไอคอนนามธรรม ตั้งแต่บรีฟแรก — ยิ่งวัตถุเป็นรูปธรรมเท่าไหร่ ยิ่งผ่าน readability test เร็วขึ้นเท่านั้น ไม่ต้องรอ Ness สั่งเพิ่มทีหลัง
