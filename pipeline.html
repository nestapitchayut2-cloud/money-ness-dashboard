สมดุลสตรีม — งานที่ยัง active ต่อสตรีม
🧭 หลักการเดียวที่ต้องจำ

ทำคลิปยาว 3–6 นาที 1 ชิ้น/สัปดาห์ให้ตกผลึก → ที่เหลือคือ "ของแถม" ที่ตัดออกมา ไม่ใช่งานใหม่

  1. แทร็ก A — คลิปยาว (flagship): 1 ตอน = 1 คำถาม/ไอเดีย · หมุน 4 รส (🔧 กลไก / 🔍 แกะ / ❓ คำถาม / 📚 บทเรียน) · ลง YouTube + พอดแคสต์
  2. แทร็ก B — English Vlog: สัปดาห์ละครั้ง คนละกลุ่ม ไม่ยุ่งกับ A
  3. แทร็ก C — คู่มือการเงิน: งานเขียน ช้าๆ 1–2 บท/เดือน
  4. ของแถม (สตรีม "โพสต์"): ตัด short 45–60 วิ จากคลิปยาว + การ์ดคำคมจากประโยคเด็ด + โพสต์ภาพเดียวถ้ามีตัวเลข — ไม่เขียนสคริปต์ใหม่

พักไว้: Reel เดี่ยว (เลิกถาวร), สตรีมตลาดรายสัปดาห์ (ยุบเป็นตอนคลิปยาวเป็นครั้งคราว). แผน 8 สัปดาห์ + คลังหัวข้ออยู่ใน content-strategy.md

🔍 แกะหุ้น 1 ตัว — เช็คลิสต์ 7 ข้อ (ทำทุกตอน = ได้เรียนจริง ไม่ใช่แค่เล่าที่รู้)
  1. ธุรกิจทำเงินจากอะไร — รายได้แยกตามส่วน (segment), ใครคือลูกค้า, คู่แข่งหลัก, moat คืออะไร (แบรนด์ / ต้นทุน / network / switching cost)
  2. ตัวเลข 5 ปี — รายได้โต, กำไร/EPS โต, gross & operating margin, ROE/ROIC, หนี้สินสุทธิ/EBITDA, กระแสเงินสดอิสระ (FCF)
  3. มูลค่า — P/E ปัจจุบันเทียบค่าเฉลี่ย 5 ปีของตัวเอง + เทียบคู่แข่ง, PEG, ลอง reverse: "ราคานี้ตลาดคาดว่าโตปีละกี่ %"
  4. Bull case 3 ข้อ — ถ้าถูกทาง อะไรจะดัน
  5. Bear case 3 ข้อ — ความเสี่ยงจริง ไม่ใช่แค่ "เศรษฐกิจไม่ดี"
  6. อะไรทำให้ thesis พัง — สัญญาณที่เจอแล้วต้องยอมขาย (ตัวเลขไหน / เหตุการณ์ไหน)
  7. สรุปของผม — ซื้อไหม / ที่ราคาเท่าไหร่ / ขนาดโพซิชันเท่าไหร่  + 1 คอนเซ็ปต์ใหม่ที่เรียนได้จากตอนนี้ (พูดปิดท้ายคลิป)
📡 ตอนสรุปตลาด (รส 🔧 กลไก, ทำเป็นครั้งคราว ไม่ใช่ทุกสัปดาห์) — โครง 4 ท่อน
  1. สัปดาห์ที่ผ่านมา — อะไรขยับและทำไม (หุ้นสหรัฐ/ไทย, บอนด์ yield, ทอง, ค่าเงินบาท, คริปโต) — เลือก 3 เรื่องพอ
  2. สัปดาห์หน้ามีอะไร — งบบริษัทที่จะประกาศ, ประชุม Fed / กนง., ตัวเลขเศรษฐกิจสำคัญ (CPI, จ้างงาน)
  3. หุ้นในลิสต์ — เพิ่ม / ตัด / เฝ้าดู ตัวไหน เพราะอะไร (เชื่อมกับคลิปแกะหุ้น)
  4. พอร์ตผมสัปดาห์นี้ — ปรับอะไร ไม่ปรับอะไร เพราะอะไร (transparency สร้างความน่าเชื่อถือ)
